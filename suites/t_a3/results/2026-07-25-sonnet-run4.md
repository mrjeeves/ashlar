**Model under test:** `claude-sonnet-5` (readers), `claude-opus-5` (judges)
**Date:** 2026-07-25
**Scope:** the two fixtures whose keywords changed in ADR-0019 — `11-peruser`
and `25-foreign-reactive`. **Not** a full corpus re-run: the other 23 snippets
are unchanged and their run-3 verdicts stand.
**Result as recorded: both PASS, corpus standing 25/25** (23 unchanged passes
from run 3 + these 2) — withdrawn per the annotation above.

Run 3 failed exactly these two snippets, unanimously, and ADR-0019 respelled
both constructs: `owned` → `peruser`, `reads`/`writes` → `watches`/`updates`.
This run asks whether the new spellings actually read the way they mean. Method
is identical to run 3: a fresh reader per snippet, given the snippet inline and
barred from touching any file, asked only "State precisely what this code
means/does."; then a three-judge panel (rubric-as-written, charitable, strict)
with the majority deciding.

## `11-peruser` — PASS, unanimous 3/3, 4/4 bullets

Every judge scored all four bullets and flagged no wrong claim. The bullet
run 3 missed — per-user scope — came back near-verbatim:

> "`peruser` — a modifier marking the field's scope as per-user: rather than one
> value shared across everyone, each user gets their own independent copy of
> `items`."

For comparison, the same bullet under `owned` (run 3) produced "state that
`Store` itself holds and manages (as opposed to a reference/prop passed in from
outside)" and a conclusion describing one shared list. The finding A3-F5 raised
is closed: the misread was in the word, and the word changed.

## `25-foreign-reactive` — PASS on a 2–1 panel, and the dissent is real

| judge | verdict | bullets |
|---|---|---|
| rubric as written | PASS | 4/4 |
| charitable | PASS | 4/4 |
| **strict** | **FAIL** | **2/4** |

Majority carries it, by the same rule that carried `03-layering` in run 3. But
the strict dissent is not noise, and it localizes precisely:

**`watches` conveys reactivity; `updates` conveys it only by association.**
The reader described `watches Row` as observing "in a way that tracks changes
to it, rather than a plain one-shot read," and said callers of `all()` are
"re-notified/kept current whenever the underlying `Row` data changes" — the
dependency edge, stated outright. But `updates Row` got only "an effect
annotation: calling `save` is declared to mutate/write the `Row` data." The
invalidation half arrived hedged, in a parenthesis: "(presumably including when
`save` runs, since both are tied to the same `Row` part)."

So the reader inferred the write side from the read side rather than from the
word `updates` itself. Two judges credited the inference; the strict judge
would not credit a "presumably."

**This is still a large improvement, not a wash.** Under `reads`/`writes` the
candidate cold read produced *no reactivity at all* — 0/2 on the candidate run,
and 2/4 with reactivity "entirely absent" in run 3. The reactive model is now
present and correctly shaped; what is weak is which of the two words carries
it.

**Recorded, not acted on.** Changing `updates` again on a 2–1 panel and a
single reader would be over-fitting to one sample — the same mistake in the
opposite direction from ADR-0015's word-level read. The honest state is: the
pair passes, the write half is the softer half, and a future run that fails
here should look at `updates` first. Candidates already scored 2/2 in the
ADR-0019 candidate run and available if it comes to that: `invalidates`.

## What run 4 does not claim

Only two fixtures were re-scored. The 25/25 standing rests on run 3 for the
other 23, whose snippets are byte-identical to what run 3 read. A full re-run
is a separate exercise, and the next one should be a full run rather than
another targeted one, so the whole corpus is scored against one model at one
time.
